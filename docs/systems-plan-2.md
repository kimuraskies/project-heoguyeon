# 2차 시스템 기획: 뉴스 허브 · 받은편지함 · 라커룸 · 구단 운영

상태: **기획 확정 (2026-11-06)**, 구현 전. 아래 결정은 감독(사용자)과 확정했다. "기본안"이라고 적힌 항목은 제안대로 진행하고, 플레이해 본 뒤 조정한다.

네 시스템은 서로 맞물린다. 사건(경기, 계약, 갈등, 투자)이 생기면 **뉴스 허브**에 기사로 남는다. 감독이 결정해야 하는 것만 **받은편지함**에 온다. **라커룸**과 **구단 운영**은 그 사건을 만들어 내는 쪽이다.

```
경기·계약·드래프트 ─┐
라커룸(관계·갈등) ──┼─▶ 사건 ─▶ 뉴스 허브 (모든 기사)
구단 운영(투자)  ──┘        └─▶ 받은편지함 (결정 필요한 것만, 나머지는 위임·자동 처리)
```

---

## A. 리그 뉴스 허브

지금의 피드는 우리 팀 경기 리포트와 언론 인터뷰 기록이 전부다. 이걸 **리그 전체 신문**으로 넓힌다.

### 화면: "뉴스" 탭 (피드 대체)
- **1면 헤드라인:** 오늘 가장 큰 기사 1건을 큰 카드로 보여 준다. 우리 팀 기사를 우선한다.
- **섹션:** 우리 팀 · 리그 · 이적시장 · 기록 · 인터뷰
- **주간 특집:** 매주 월요일에 낸다.
  - 주간 MVP(타자·투수)
  - 파워랭킹(10개 구단 1~10위와 한 줄 평)
  - "이번 주의 장면"

### 기사 종류

| 종류 | 생성 조건 | 예 |
|---|---|---|
| 경기 | 우리 경기 (구현됨) + 타 구단의 큰 경기(노히트, 10점 차, 끝내기) | "SSG, 9회말 끝내기로 4연승" |
| 순위 | 1위 교체, 5위 싸움, 매직넘버 | "LG, 41일 만에 선두 탈환" |
| 기록 | 시즌·통산 이정표: 100안타, 20홈런, 10승, 통산 2000안타 | "○○, 역대 ○번째 통산 300홈런" |
| 이적시장 | AI 구단 간 트레이드, FA 계약, 외국인 교체, 방출 | "삼성, 외국인 투수 교체 단행" |
| 루머 | 트레이드 마감 2주 전부터: 우리 선수 또는 타 구단 선수 이적설 (30%는 사실무근) | "○○, 트레이드 시장에 나왔다?" |
| 부상 | 주전급 장기 부상 (우리 팀과 타 구단) | |
| 인터뷰 | 감독 답변 (구현됨) + 타 구단 감독 코멘트 | |
| 라커룸 | C절의 갈등·화합 사건 (가려서 보도) | "덕아웃 불화설… 구단은 부인" |

### 규칙
- 기사는 템플릿 + 실제 데이터로 만든다. 문장 변형은 2~4개씩 둔다.
- 하루 기사 상한은 6건이다. 중요도 점수로 거르고, 우리 팀 관련은 +50점이다.
- 우리 팀 관련 기사는 **팬 여론**에 작게 영향을 준다. 루머 기사는 해당 선수 사기에 -2다.
- 기사에서 선수 이름을 누르면 선수 프로필 페이지로 간다.

### 데이터
`f.news = [{id, day, year, sec, imp, title, body, teams[], players[]}]`. 최근 300건만 보관한다.

### 결정
- 타 구단 감독은 **실명**(2026 시즌 감독)으로 한다. 코멘트는 중립적인 말투만 쓰고, 논란성 발언은 만들지 않는다.
- 파워랭킹 한 줄 평은 담백한 스포츠 기사 톤으로 한다 (기본안).

## B. 받은편지함 정리 · 위임

지금은 모든 연락이 한 목록에 쌓인다. 결정 메시지, 단순 보고, 언론 요청이 섞여 있다.

### 세 칸 분리

| 칸 | 내용 | 예 |
|---|---|---|
| **결정 필요** | 버튼이 있는 메시지. 기한(D-n)을 표시하고, 기한이 지나면 기본 선택으로 처리 | 재계약, 트레이드 제안, 면담 요청, 인터뷰 |
| **보고** | 읽기만 하면 되는 것 | 이사회 평가, 부상 소식, 코치 리포트 |
| **자동 처리됨** | 위임 규칙으로 코치·단장이 처리한 것. 결과만 기록 | "수석코치가 ○○에게 휴식을 줬습니다" |

### 위임 설정 (구단 탭 "업무 분담")

| 업무 | 담당 | 감독이 고르는 것 |
|---|---|---|
| 휴식 관리 | 수석코치 | 직접 / 위임 (구현됨: autoRest) |
| 경기 전·구단 채널·지역 인터뷰 | 홍보팀 | 직접 / 무난하게 답변 / 모두 사양 |
| 선수 면담 요청 | 수석코치 | 직접 / 위임(사기 효과 70%) |
| 2군 콜업·말소 추천 | 2군 감독 | 직접 / 추천만 / 자동 |
| 소액 트레이드 제안 거절 | 단장 | 직접 / 가치 차이 큰 제안 자동 거절 |
| 계약 만료 선수 재계약 | 단장 | 직접 / 주전급만 직접 |

- 위임하면 효율은 조금 낮다. 예를 들어 면담을 위임하면 효과가 70%다.
- 대신 플레이 시간이 줄어든다. FM의 staff responsibilities에 해당한다.

### 그 밖의 정리
- 같은 종류 보고는 하루에 묶는다. 예: 부상 3건이면 "부상 리포트 (3명)" 한 통으로 보낸다.
- 대시보드의 "지금 결정할 일"은 **결정 필요** 칸과 연결한다.
- 기한이 3일 이하인 것은 빨간 배지로 표시한다.

### 결정
- 기한이 지나면 **기본 선택으로 자동 처리**하고 "자동 처리됨" 칸에 기록한다.
- 위임 범위는 위 표 전체로 한다 (기본안).

## C. 선수 관계 · 라커룸

### 관계
- 같은 팀 선수 쌍마다 친밀도 `rel`(−100~100)을 둔다. 의미 있는 쌍만 저장한다(|rel| ≥ 20).
- **올라가는 경우:**
  - 같은 출신(같은 고교·대학 데이터가 있으면, 없으면 같은 데뷔 연도)
  - 같은 포지션 그룹에서 오래 함께 뛰기(시즌당 +5)
  - 멘토링(아래)
- **내려가는 경우:**
  - 같은 포지션 주전 경쟁에서 밀린 쪽(−10)
  - 공개 질책을 받은 선수와 그 친한 선수(−5)
- 친한 선수가 트레이드나 방출로 떠나면 남은 선수 사기가 −4~−8이다. 그래서 트레이드에 감정 비용이 생긴다.

### 라커룸 구조
- **리더 그룹:** 성격이 '리더형'이거나, 30세 이상이면서 OVR이 높고 입단 4년 이상인 선수 중 최대 3명이다.
  - 리더 사기가 팀 평균 사기에 가중치 2배로 들어간다.
  - 리더가 불만이면 "라커룸 분위기 악화" 사건이 생긴다.
- **분위기 지수(0~100):**
  - 구성: 평균 사기, 리더 사기, 갈등 수, 최근 성적
  - 70 이상: 접전 경기력 +1%, 사기 회복 빠름
  - 30 이하: 사기 하락이 연쇄적으로 번짐
- **멘토링:**
  - 베테랑 1명을 25세 이하 유망주 1명과 묶는다(최대 3쌍).
  - 유망주의 성장 확률이 +10%다.
  - 성격 일부가 옮겨 간다. 예: '프로페셔널' 멘토는 예민함을 낮춘다.
  - 둘의 친밀도가 오른다.

### 사건 (받은편지함 결정)

| 사건 | 조건 | 선택지 |
|---|---|---|
| 주전 경쟁 불만 | 비슷한 OVR 두 선수, 한 명이 10경기 이상 벤치 | 기회 약속 / 경쟁 강조 / 트레이드 리스트 |
| 덕아웃 충돌 | rel −60 이하 쌍, 연패 중 | 둘 다 면담 / 한쪽 편들기 / 무시 (언론 보도 확률) |
| 리더의 건의 | 리더 사기 낮음 | 팀 미팅 / 요구 수용(휴식, 기용) / 거절 |
| 베테랑 은퇴 고민 | 36세 이상, 성적 하락 | 은퇴 만류 / 지도자 제안(코치 풀에 추가) / 존중 |

### UI
- 스쿼드 탭에 "라커룸" 하위 탭을 둔다. 리더 그룹, 분위기 지수, 친한 그룹과 갈등 쌍 목록, 멘토링 슬롯이 들어간다.
- 선수 프로필에 "관계" 섹션을 둔다. 가장 친한 3명과 사이 나쁜 1명을 보여 준다.

### 결정
- 실존 선수에게는 **주전 경쟁 불만 수준까지만** 만든다.
  - 덕아웃 충돌, 불화설 기사, rel −60 이하 사건은 가상 선수끼리만 생긴다. 가상 선수는 드래프트 신인과 외국인 가상 후보 등이고, `p.fic` 표시로 구분한다.
  - 실존 선수의 친밀도는 0 이상으로만 움직이고, 경쟁에서 밀린 경우만 −로 내려간다(최저 −30).
- 분위기 지수가 경기에 주는 영향은 ±1%로 한다 (기본안).

## D. 구단 운영 · 투자

지금 재정은 잔고, 연봉 예산, 관중 수입이 전부다. 잔고를 **쓸 곳**을 만든다.

### 시설 (레벨 1~5, 단계마다 비용과 공사 기간)

| 시설 | 효과 (레벨당) | 비용 (억) | 공사 |
|---|---|---|---|
| 1군 훈련 시설 | 1군 성장 확률 +4% | 8 / 12 / 18 / 25 | 오프시즌에만 |
| 2군 구장·숙소 | 2군 성장 확률 +6%, 유망주 사기 +2 | 6 / 10 / 15 / 22 | 오프시즌에만 |
| 의무·재활 센터 | 부상 기간 −8%, 캠프 부상 −10% | 5 / 9 / 14 / 20 | 오프시즌에만 |
| 전력분석실 | 상대 분석도 +5%p, 드래프트 예상 정확도 상승 | 4 / 7 / 11 / 16 | 언제나 |
| 구장 편의시설 | 관중 +3%, 객단가 +2% | 7 / 12 / 18 / 26 | 오프시즌에만 |

- 유지비는 레벨 × 0.5억/시즌이다.
- 레벨은 구단마다 다르게 시작한다. 예: 신축 구장 구단은 편의시설 4. AI 구단도 투자한다.

### 스카우트 네트워크
- 스카우트 수는 1~6명이고, 1명당 연봉 0.5억이다.
- 효과: 드래프트 후보 잠재력 표시 정확도(지금은 `estPot` 오차), 외국인 후보 수, 숨은 유망주 발견 확률
- 지역 배정: 국내 고교·대학 / 미국 / 일본·대만 / 중남미
  - 배정한 지역의 외국인 후보가 더 많고 더 정확하게 보인다.
  - 감독 경력 'MLB 전문가' 보너스와 겹친다.

### 이사회와의 예산 협상
- 시즌 종료 후 이사회 평가 때 요청을 1회 할 수 있다.
  - 시설 투자 승인
  - 연봉 예산 증액
  - 스카우트 증원
- 승인 확률 = 이사회 신뢰도 + 성적 + 팬 여론
- 거절되면 신뢰도 −2, 무리한 요청이면 −5다.

### 수입 구조 보강
- 관중 수입(구현됨)
- 중계권(고정)
- 스폰서: 팬 여론과 성적으로 시즌 계약 금액을 정한다.
- 포스트시즌 배당
- 굿즈: 인기 선수 수에 비례

### UI
- 구단 탭을 하위 탭으로 나눈다: 이사회 · 재정 · 시설 · 스카우트 · 코칭스태프 · 업무 분담
- 시설은 카드형으로 보여 준다. 레벨 막대, 다음 레벨 효과, 비용, "투자" 버튼이 있다.

### 결정
- 시설 투자는 **이사회 승인**을 거친다. 시즌 종료 후 요청 1회, 승인되면 오프시즌에 공사한다.
  - 전력분석실만 시즌 중에도 요청할 수 있다(소액).
- 구장 레벨은 실제 구장 사정에 맞춰 차등 시작한다 (기본안). 수치는 구현할 때 표로 확정한다.

## 구현 순서 제안

| 순서 | 작업 | 이유 |
|---|---|---|
| 1 | B. 받은편지함 세 칸 + 위임 | 기능이 늘수록 메시지가 폭증하므로 먼저 정리해야 한다 |
| 2 | A. 뉴스 허브 | 나머지 시스템의 결과가 보이는 창구다 |
| 3 | D. 구단 운영·투자 | 잔고에 쓸 곳이 생긴다. 프리시즌 스토브리그와 맞물린다 |

프리시즌 3단계(별도 문서)는 1과 2 사이에 넣는다. 스토브리그를 주 단위로 진행하면 받은편지함 정리가 먼저 필요하기 때문이다.

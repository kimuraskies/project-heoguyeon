# 코칭스태프 기획서

상태: **기획 확정 (2026-11-07)**, 구현 전.

확정된 결정:
- 조직은 **10자리**로 한다.
- 능력치는 **우리 코치는 정확한 숫자, 영입 후보는 범위**로 보여 준다(전력분석팀장이 좋을수록 범위가 좁다).
- 실존 코치는 **10개 구단 공식 명단으로 채우고**, 확인되지 않는 자리만 가상으로 둔다.
- 건의를 계속 무시하면 **만족도가 떨어지고, 시즌 후 사의**를 표명할 수 있다.

## 지금의 문제

현재 코칭스태프는 **표 한 장**이다. 보직 6개(수석·투수·타격·수비·주루·배터리)가 있고, 코치마다 능력치 하나(1~20)만 있다. 효과는 성장 확률 배율과 전술 숙련 속도뿐이다.

- 감독이 코치를 바꿔도 체감이 거의 없다.
- 코치가 말을 하지 않는다. 보고서도, 건의도, 성격도 없다.
- 영입은 매 시즌 무작위 가상 후보 중에서 고르는 게 전부다.
- 2군 코치진, 트레이닝 파트, 전력분석이 없다.

**목표:** 코치를 "내가 고른 사람들"로 느끼게 한다. 코치는 세 가지 방식으로 존재감을 가진다.
1. **보고한다:** 받은편지함, 캠프, 경기 전
2. **영향을 준다:** 성장, 전술, 컨디션, 분석
3. **관계를 가진다:** 선수, 감독

## 1. 조직도 (기본안: 10자리)

| 파트 | 보직 | 담당 영역 |
|---|---|---|
| 1군 | 수석코치 | 전술 숙련, 선수단 분위기, 감독 부재 시 대행 |
| 1군 | 투수코치 | 선발 성장·투구 수 관리, 불펜 운용 조언 |
| 1군 | 불펜코치 | 불펜 피로 관리, 마무리·셋업 컨디션 |
| 1군 | 타격코치 | 타자 성장(컨택·파워·선구), 슬럼프 관리 |
| 1군 | 수비코치 | 수비·송구 성장, 포지션 전환 |
| 1군 | 주루코치 | 주력 활용, 도루 성공률, 작전 수행 |
| 1군 | 배터리코치 | 포수 성장, 투수-포수 호흡, 상대 분석 활용 |
| 지원 | 컨디셔닝코치 | 부상 위험, 회복 속도, 캠프 강도 |
| 지원 | 전력분석팀장 | 상대 분석도, 스카우팅 리포트 정확도 |
| 2군 | 퓨처스 감독 | 2군 성장·콜업 추천의 정확도 |

**결정:** 10자리로 간다.

## 2. 코치 프로필

| 항목 | 내용 |
|---|---|
| 기본 | 이름, 나이, 출신(선수 출신 포지션 / 비선수 출신), 경력 연수 |
| 능력치 (1~20) | **지도력**(성장), **전술**(작전 이해·숙련), **분석**(상대·데이터), **동기부여**(사기), **관리**(체력·부상) |
| 전문 분야 | 보직 안의 세부 특기 1~2개. 예: 투수코치 "제구 교정", 타격코치 "장타력", 수비코치 "내야 수비" |
| 성향 | **육성형** / **성적형** / **데이터형** / **올드스쿨** 중 하나 |
| 계약 | 연봉, 남은 기간(1~3년), 재계약 의사 |
| 관계 | 감독과의 궁합, 특정 선수와의 인연(사제·같은 출신) |

**성향의 효과 (예시)**
- **육성형:** 25세 이하 성장 +, 베테랑 기용 건의 −
- **성적형:** 주전 컨디션 관리 +, 유망주 기회 건의 −
- **데이터형:** 분석·전술 숙련 +, 선수 사기 관리 −
- **올드스쿨:** 선수단 규율·투지 +, 데이터 전술 숙련 −

**감독과의 궁합:** 감독 경력(신인·코치 출신·레전드·KBO 전문가·MLB 전문가)과 코치 성향이 맞으면 코치 효과 +10%, 안 맞으면 −10%다. 예: MLB 전문가 감독 + 데이터형 코치는 궁합이 좋다.

## 3. 효과: 능력치가 실제로 하는 일

| 코치 | 쓰는 능력치 | 게임 효과 (지금 → 바꾼 뒤) |
|---|---|---|
| 수석 | 전술·동기부여 | 전술 숙련 속도(구현됨) + 연패 시 사기 하락 완화 |
| 투수 | 지도력 + 전문 | 투수 성장 배율(구현됨). 전문 분야 능력치에 성장이 몰린다(예: 제구 교정 → ctl) |
| 불펜 | 관리 | 불펜 투수 컨디션 회복 +, 연투 피로 − |
| 타격 | 지도력 + 전문 | 타자 성장 배율(구현됨). 전문 분야에 집중 + 슬럼프 탈출 속도 |
| 수비 | 지도력 | 수비·송구 성장, 포지션 전환 기간 단축(캠프 과제와 연결) |
| 주루 | 전술 | 도루 성공률 ±, 히트앤런 수행도 |
| 배터리 | 분석 | 포수 성장 + 상대 분석도가 경기에 반영되는 정도 |
| 컨디셔닝 | 관리 | 부상 확률 −, 부상 기간 −, 캠프 강도 부상 위험 − |
| 전력분석 | 분석 | 상대 분석도 시작값 +, 드래프트·외국인 능력치 표시 오차 − |
| 퓨처스 감독 | 지도력·분석 | 2군 성장 + 콜업 추천의 정확도 |

**밸런스 원칙:** 코치 한 명의 효과는 ±10% 안쪽으로 둔다. 전체가 최상급이어도 성장 +25% 정도로 묶어서, 코치진이 선수 영입보다 우선이 되지 않게 한다. QA 하네스에 "코치진 최상 vs 최하 10시즌" 비교 항목을 추가한다.

## 4. 코치가 말을 한다: 보고서와 건의

받은편지함 "보고" 칸에, 업무 분담 위임과 연결해서 온다.

| 시점 | 보낸 사람 | 내용 | 결정 |
|---|---|---|---|
| 매주 | 투수코치 | 선발 로테이션 피로도, 다음 주 추천 순서 | 추천 적용 / 유지 |
| 매주 | 타격코치 | 슬럼프 선수 1~2명과 처방(휴식 / 타순 조정 / 특타) | 처방 선택 |
| 연패 3+ | 수석코치 | 분위기 보고, 팀 미팅 건의 | 미팅 / 보류 |
| 부상 위험 | 컨디셔닝코치 | 위험 선수 목록, 휴식 권고 | 휴식 / 강행 |
| 시리즈 전 | 전력분석팀장 | 상대 3연전 요약(에이스, 약점, 추천 작전) | 참고 (작전 자동 적용 옵션) |
| 월 1회 | 퓨처스 감독 | 2군 TOP 3, 콜업 추천 | 콜업 / 보류 (구현된 보고를 확장) |
| 캠프 주말 | 수석코치 | 주간 캠프 결과(프리시즌 사양서와 연결) | — |

- **성향이 말투와 추천에 묻어난다.** 육성형 코치는 유망주 기용을, 성적형은 주전 휴식 최소화를 건의한다.
- **건의를 받아들이면** 그 코치의 만족도가 오른다. 계속 무시하면 만족도가 떨어지고, 결국 시즌 후 사의를 표명할 수 있다.

## 5. 영입과 이탈

- **시장:** 스토브리그 주 단위 진행(프리시즌 사양서)과 같은 틀을 쓴다.
  - 1주차: 계약 만료 코치가 FA 코치 풀에 들어간다.
  - 다른 구단 코치를 데려오려면 해당 코치의 수락이 필요하다. 조건은 보직 승격, 연봉, 감독 궁합이다.
- **면접:** 후보 코치와 짧은 면접(질문 2개)을 본다. 성향이 드러나고, 답에 따라 연봉 요구가 바뀐다.
- **시즌 중 교체:** 1회만 가능하다(사양서 확정 사항).
- **이탈 사유:**
  - 계약 만료
  - 만족도 저하로 인한 사의
  - 다른 구단의 감독 제의(우수 수석코치)
  - 은퇴
- **선수 → 코치:** 은퇴하는 베테랑(라커룸 사양서의 "지도자 제안")이 코치 풀에 들어간다. 우리 팀 레전드를 코치로 앉히는 서사가 생긴다.

## 6. 화면

- **구단 탭 → 코칭스태프 하위 탭**
  - 조직도 카드: 1군 / 지원 / 2군
  - 코치마다 사진 대신 이니셜 원, 성향 배지, 능력치 막대 5개, 만족도
- **코치 프로필 페이지:** 선수 프로필과 같은 전체 화면 형식
  - 능력치, 전문 분야, 성향, 계약, 인연 선수
  - 올 시즌 기여: "지도한 선수 성장 +12", "건의 수용률 70%"
- **대시보드:** "코치 한마디" 카드 1장. 이번 주 가장 중요한 건의를 보여 준다.

---

## 7. 데이터

- **실존 코치:** 현재 실명 4명(LG 2, 두산 1, 키움 1)뿐이다.
  - **결정:** 10개 구단 공식 코치진 명단(구단 발표·KBO 등록 현황)을 모아서 채운다. 보직이 확인되지 않는 자리만 가상(표시 유지)으로 둔다.
- **능력치:** 실존 인물은 경력에서 추정한다(게임용 수치임을 명시).
  - 예: 투수 출신 → 투수 지도력 보정, 코치 경력 연수 → 전술

## 구현 순서 (제안)

| 순서 | 작업 | 크기 |
|---|---|---|
| 1 | 코치 프로필 확장(능력치 5개, 전문, 성향, 계약) + 효과 재배선 + 보직 10개 | 중 |
| 2 | 코치 보고서·건의 6종 + 만족도 | 중 |
| 3 | 코칭스태프 화면(조직도, 코치 프로필 페이지) | 중 |
| 4 | 스토브리그 코치 시장·면접 (프리시즌 주 단위 진행과 함께) | 대 |
| 5 | 선수 → 코치 전환, 다른 구단 감독 제의 | 소 |

프리시즌 3단계와 묶으면 이렇게 진행한다.
1. 코치 프로필·효과(1)
2. 스프링캠프 4주(캠프 성과에 코치 반영)
3. 코치 보고서(2)
4. 화면(3)
5. 스토브리그 주 단위 + 코치 시장(4)

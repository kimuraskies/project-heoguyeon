# 0.3 패치 기획: "시즌 밖에서도 할 일이 있는 게임"

상태: **범위 확정 (2026-11-07)**. A1~A6과 B1~B8 **전부** 0.3에 넣는다.

확정된 결정:
- 경기 후 요약은 **중계로 본 경기에서만** 뜬다. "5경기 빠르게" 같은 일괄 진행에서는 뜨지 않는다.
- 처음 온 감독 안내는 **수석코치 말풍선** 방식이다(첫 커리어에서만, 건너뛰기 가능).

## 패치 목표

지금 게임은 **정규시즌 경기**는 재미있지만, 그 밖의 시간이 비어 있다. 스토브리그·캠프는 버튼 몇 번이면 지나가고, 코치는 표 한 장이다. 경기가 끝나면 결과가 흩어진다.

0.3 패치는 **경기와 경기 사이, 시즌과 시즌 사이**를 채운다. 지인 테스트를 시작하는 만큼, 처음 온 사람이 길을 잃지 않게 하는 것도 포함한다.

## B. 새로 제안하는 항목

### B1. 경기 후 요약 화면 (중)
경기 종료 후 한 화면에 모아 보여 준다.
- 최종 스코어와 이닝 점수, 승·패·세이브 투수
- **수훈 선수(MOM)**와 우리 팀 평점 TOP 3 / 하위 1
- **승리 확률 그래프**(이닝별 흐름, 가장 큰 장면 표시)
- 코치 한마디(코치 성향에 따라 다른 말, A4와 연결)
- 경기 후 인터뷰가 있으면 바로 답하기
- 다음 경기와 다음 단계 버튼

→ 경기 → 결과 → 다음 경기 흐름이 하나로 닫힌다. 지금 가장 체감이 큰 공백이다.

### B2. 세이브 내보내기·가져오기 (소)
- 설정 → **세이브 파일 받기**(.json 다운로드), **세이브 파일 불러오기**
- 자동 백업: 시즌 종료 시 직전 시즌 세이브를 브라우저에 1개 보관
- 지인 테스트 중 커리어 유실(브라우저 데이터 삭제, 기기 변경)을 막는다.

### B3. 처음 온 감독 안내 (소)
- 첫 커리어에서만 뜨는 **코치 안내 말풍선 5개**: 상단 다음 단계 버튼 → 받은편지함 → 라인업 → 경기 준비 → 중계 작전
- 수석코치가 말하는 형식(A4 코치 이름 사용), 건너뛰기 가능
- 설명서 페이지 없이도 첫 경기까지 가게 만든다.

### B4. 리그 뉴스 허브 (중)
systems-plan-2.md §A에 확정된 내용이다.
- 1면 헤드라인, 섹션(우리 팀·리그·이적시장·기록·인터뷰)
- 주간 MVP와 파워랭킹
- 타 구단 큰 경기, 기록 달성, 트레이드 루머
- 피드 탭을 "뉴스"로 대체한다.

### B5. 시즌 리캡과 시상식 (소~중)
- 시즌 종료 시 **연말 시상식**: MVP, 신인왕, 골든글러브(포지션별), 타이틀(타율·홈런·다승 등)
- 우리 구단 시즌 리캡 카드: 성적, 이사회 평가, 공약 결과, 성장한 선수
- 다음 시즌으로 넘어가는 "의식"이 생긴다.

### B6. 모달 접근성·키보드 (소)
디자인 교차 검토에서 나온 1순위다.
- 닫기 버튼을 실제 버튼으로 바꾸고, Esc로 모든 창이 닫히게 한다.
- 창이 열리면 초점이 창 안으로 옮겨진다.

### B7. 코드 정리: fm.js 분리 (중, 눈에 안 보임)
- 218KB 한 파일을 기능별로 나눈다: 받은편지함, 언론, 코치, 재정, 달력, 드래프트, UI.
- 0.3의 큰 기능(A2~A5)을 넣기 **전에** 하면 이후 작업이 빨라지고 충돌이 줄어든다.

### B8. 밸런스 QA 확장 (소, 눈에 안 보임)
- QA 하네스에 새 시스템 검사를 추가한다.
  - 코치진 최상 vs 최하
  - 캠프 부상률
  - 경기 감각 범위
  - FA가 모두 정리되는지
  - 팬 여론 범위
- 61시즌 QA가 새 기능까지 지키게 된다.

## 진행 순서 (전체 범위, 묶음 5개)

| 묶음 | 내용 | 끝나면 보이는 것 |
|---|---|---|
| **1. 기반** | B7 fm.js 분리 · B8 QA 확장 · B2 세이브 내보내기·가져오기 · B6 접근성 | 세이브 파일 받기/불러오기, Esc로 닫히는 창 |
| **2. 코칭스태프** | A4 코치 10자리·프로필·효과·보고서·만족도·화면 · A6 실존 코치 데이터 | 구단 → 코칭스태프 조직도, 코치 프로필, 코치 보고서 |
| **3. 캠프와 시범경기** | A2 스프링캠프 4주(코치 효과 반영) · A1 경기 감각·출전 계획 | 4주 캠프 화면과 주간 보고, 경기 감각 수치 |
| **4. 스토브리그** | A3 주 단위 진행·FA 경쟁 입찰 · A5 코치 시장·면접 | 12주 스토브리그, FA 입찰 경쟁, 코치 면접 |
| **5. 경기와 시즌의 흐름** | B1 경기 후 요약 · B4 리그 뉴스 허브 · B5 시상식·리캡 · B3 처음 온 감독 안내 | 경기 후 화면, 뉴스 탭, 연말 시상식, 첫 커리어 안내 |

**순서를 이렇게 정한 이유:**
- 1번 기반 작업이 이후 묶음의 충돌과 회귀를 줄인다.
- 코치(2)가 먼저 있어야 캠프(3)와 스토브리그 코치 시장(4)이 코치를 쓴다.
- 처음 온 감독 안내(B3)는 화면이 다 바뀐 뒤 마지막에 만든다. 그래야 안내가 최종 화면을 가리킨다.

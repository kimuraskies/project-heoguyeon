# 중간 점검과 작업 방법 (2026-11-17)

0.7 미리보기까지 만든 시점의 평가예요. 작업지시서는 [orders-0.8.md](orders-0.8.md)에 있어요.

## 1. 게임 피드백

### 잘 된 것
- **시뮬레이션을 믿을 수 있어요.** 61시즌 자동 점검 위반 0건, 리그 수치·타구·트레이드 감사가 모두 스크립트로 남아 있어요. 기능을 얹어도 무너지지 않는 바닥이 있어요.
- **한 번 시작한 사람은 끝까지 가요.** 한 경기라도 한 160명 중 92명(58%)이 한 시즌 144경기를 다 채웠어요.
- **KBO 팬이 원하는 깊이가 생겼어요.** 실제 로스터, 세이버 리포트, 계약 가치 기반 트레이드와 팬·언론 반응까지 3주 만에 올라왔어요.
- **피드백과 사용량을 직접 볼 수 있어요.** 판단을 숫자로 할 수 있는 구조예요.

### 문제 (중요한 순서)

**① 가장 많이 빠지는 곳은 접속 코드 화면이에요.** (0.71 작업 중 정정)
처음에는 "65%가 한 경기도 하지 않는다"고 적었는데, `usage_players`가 정규시즌 경기만 세서 생긴 착오였어요. 기존 화면·행동 기록(`events`)으로 다시 센 단계별 기기 수(11/10~11/17)는 이래요.

| 단계 | 기기 | 접속 코드 화면 대비 |
|---|---|---|
| 접속 코드 화면 | 510 | 100% |
| 구단 선택 화면 | 384 | 75% |
| 커리어 시작 | 313 | 61% |
| 첫 경기 시작 | 252 | 49% |
| 첫 경기 끝 | 218 | 43% |
| 시즌 완주 | 89 | 17% |

접속 코드에서 4명 중 1명이 나가고, 구단 선택에서 커리어 시작까지 또 18%가 빠져요. 이 표는 Supabase `usage_funnel` 뷰에서 바로 볼 수 있어요(`saw_gate`, `finished_season` 열 추가).

**② 방문이 스레드 글에 달려 있어요.**
하루 방문 기기가 11/11 231대에서 11/16 40대로 줄었어요. 돌아올 이유(어제 하던 시즌의 다음 장면)가 약해요.

**③ 리포트가 결정으로 이어지지 않아요.**
세이버 리포트와 트레이드 평가는 읽을거리예요. 히트맵을 보고 승부 방식을 바꾸거나, 리포트가 "이 선수를 이렇게 써 보라"고 권하는 연결이 없어요. 0.6 계획의 "운영 연결"이 빠진 채로 남았어요.

**④ 두 번째 시즌부터 같은 장면이 나와요.**
스토브·캠프 이벤트가 약 18종이고 조건 없이 무작위예요. 0.8에서 다뤄요.

**⑤ 사실 오류가 신뢰를 깎아요.**
구종이 실제와 달라요(양현종 스플리터). SSG 외국인 선수가 4명이에요. 잠재력 검토표의 표시 87건은 아직 아무도 보지 않았어요. 야구 팬은 한 군데 틀리면 전체를 의심해요.

**⑥ 출시가 너무 잦아요.**
이틀에 세 버전(0.5.1, 0.6, 0.7)이에요. 버전마다 공지 팝업이 뜨고, 각 버전이 먹혔는지 볼 시간이 없어요.

**⑦ 작업 과정의 빈틈**
- 61시즌 점검 중에 화면 파일을 고쳐서 "소스 변경 없음" 확인이 두 번 깨졌어요.
- 스크린샷 스크립트가 저장소 밖 임시 폴더에 있어서 세션이 지워지면 사라져요.
- 새 fm 파일을 내보내기 목록에 손으로 등록해야 하고, 빠뜨려도 테스트가 잡지 못해요.

## 2. 작업 방법 제안

### 역할
| 누구 | 하는 일 |
|---|---|
| 하늘님 | 지시서 승인, 미리보기에서 재미 판단, "배포해" |
| Fable | 방향과 지시서 작성, 릴리스 전 점검. 구현은 하지 않아요 |
| Opus 5.5 | 화면·문구·통합·배포·보고. Codex 실행과 병합도 맡아요 |
| Codex | 엔진·감사 스크립트·테스트·61시즌 점검 |

### 규칙
1. **지시서 한 장으로 일해요.** 목표, 끝났다는 기준(숫자), 건드릴 파일, 건드리면 안 되는 것, 돌릴 점검, 보고 형식. 지시서에 없는 기능은 만들지 않고 "제안"으로만 보고해요.
2. **파일 소유를 나눠요.** 같은 파일을 둘이 동시에 고치지 않아요. 둘이 만나는 지점은 지시서의 "약속(인터페이스)"에 먼저 적어요.
3. **관문 네 개를 차례로 지나요.** 지시서 승인 → 자동 점검 통과 → 미리보기와 휴대폰 스크린샷 → 하늘님의 "배포해".
4. **주 1회, 주제 하나로 출시해요.** 급한 버그는 따로 바로 고쳐요. 출시 뒤 3일은 숫자를 보고 다음 지시서에 반영해요.
5. **61시즌 점검은 고정된 사본에서 돌려요.** 도는 동안 다른 작업을 해도 결과가 흔들리지 않게요.
6. **출시마다 보는 숫자를 정해요.** 0.8은 "첫 경기 도달률"과 "두 번째 시즌 도달률"이에요.

# 오프시즌 재설계: 매주 고민거리 하나

작성 2026-11-10. 상태: 방향 승인, 세부 확정 전.

## 왜 바꾸나

지금 스토브리그 12주, 캠프 4주, 시범경기 10경기는 길지만 결정할 것이 거의 없다. 직접 플레이했을 때 스토브리그에서 내린 결정은 FA 입찰 1건이었고, 캠프 결과는 배분과 상관없이 비슷했고, 시범경기 뒤에는 전원이 경기 감각 100이 됐다.

건너뛰기는 지루함만 줄인다. 재미는 **대가가 있는 선택**과 **나중에 돌아오는 결과**에서 나온다.

## 원칙

1. 한 주에 큰 결정은 하나. 하나를 얻으면 하나를 포기한다.
2. 모든 결정은 시즌 중에 결과로 돌아온다. 돌아올 때 "그때 그 결정"임을 알려 준다.
3. 자원이 빠듯해야 한다. 예산, 엔트리 자리, 코치의 시간, 선수의 신뢰.
4. 건너뛰기는 남긴다. 건너뛰면 단장과 수석코치가 무난한 쪽으로 대신 고른다.

## 전체 흐름

스토브리그 **12주 → 6주**, 캠프 4주 유지, 시범경기 **10경기 → 6경기**.

| 주 | 구간 | 그 주의 결정 |
|---|---|---|
| 1 | 스토브리그 | 구단주 면담: 올해 방향(우승 도전 / 균형 / 리빌딩). 예산과 이사회 기대치가 달라진다 |
| 2 | 스토브리그 | 재계약: 만료 선수 가운데 예산으로 전부 잡을 수 없다 |
| 3 | 스토브리그 | FA 1차: 대어 면담과 조건 제시 |
| 4 | 스토브리그 | 트레이드 주간: 다른 구단의 제안 2~3건 가운데 고르거나 거절 |
| 5 | 스토브리그 | FA 2차와 외국인: 남은 예산으로 마지막 보강 |
| 6 | 스토브리그 | 코치진 정비: 떠나려는 코치, 영입 후보, 보직 |
| 7~10 | 캠프 | 주마다 캠프 사건 1건 |
| 11~ | 시범경기 | 주전 경쟁 2~3자리 결판 |

## 1. 스토브리그

### 주간 사건 카드

매주 대시보드 맨 위에 **이번 주의 사건** 한 장이 뜬다. 답해야 다음 주로 넘어간다. 답은 2~3개이고 각각 얻는 것과 잃는 것이 적혀 있다.

고정 사건(위 표) 외에 주마다 돌발 사건이 0~1건 붙는다.

| 돌발 사건 | 선택 | 대가 |
|---|---|---|
| 에이스가 연봉 인상 요구 | 들어준다 / 내년으로 미룬다 / 거절 | 예산 / 내년 재계약 요구 상승 / 사기 하락, 트레이드 요청 가능 |
| 라이벌이 우리 FA 목표에 입찰 | 조건을 올린다 / 주전 보장을 건다 / 포기 | 예산 / 약속 불이행 시 신뢰 하락 / 전력 공백 |
| 유망주를 달라는 트레이드 | 받는다 / 다른 선수로 역제안 / 거절 | 미래 전력 / 성사 확률 하락 / 없음 |
| 베테랑이 은퇴 고민 | 1년 더 설득 / 코치 제안 / 보내 준다 | 엔트리 한 자리 / 코치 자리 / 라커룸 리더 공백 |
| 팬 여론: 프랜차이즈 스타 이적설 | 잔류 선언 / 침묵 / 트레이드 검토 | 협상력 하락 / 여론 하락 / 여론 크게 하락, 전력 보강 기회 |
| 외국인 선수 재계약 줄다리기 | 요구 수용 / 새 후보 탐색 / 줄다리기 | 예산 / 미지수 / 계약 불발 위험 |

### FA: 입찰에서 협상으로

- 대어(OVR 상위)는 **면담**을 한다. 선수마다 원하는 것이 다르다: 돈, 주전 보장, 우승 전력, 고향 팀, 계약 기간.
- 경쟁 구단의 제안이 대략 보인다("연봉 7억대, 3년").
- 우리 카드는 연봉, 기간, **약속**(주전 보장, 특정 타순, 마무리 보직)이다.
- 약속은 시즌 중 추적한다. 지키면 사기 상승, 어기면 본인과 선수단 신뢰 하락. 지금의 출전 약속 시스템을 그대로 쓴다.
- 결정은 그 주 안에 난다. 기다리는 주가 없다.

### 구단주 면담(1주차)

| 방향 | 예산 | 이사회 목표 | 기타 |
|---|---|---|---|
| 우승 도전 | +15% | 한 단계 상향 | 실패 시 신뢰 크게 하락 |
| 균형 | 그대로 | 그대로 | |
| 리빌딩 | −10% | 한 단계 하향 | 25세 이하 성장 +, 올해 성적 압박 완화 |

## 2. 스프링캠프

포인트 배분은 없앤다. 대신 **캠프 방향 하나**(지금의 6가지)를 고르고, 4주 동안 주마다 사건이 한 건 온다.

| 캠프 사건 | 선택 | 결과가 돌아오는 때 |
|---|---|---|
| 신인 투수에게 새 구종 | 가르친다 / 기존 구종을 다듬는다 | 성공하면 무브먼트 크게 상승, 실패하면 시즌 초 제구 난조. 첫 승 때 "캠프에서 익힌 그 공" |
| 베테랑이 훈련 강도에 불만 | 강행 / 베테랑만 조절 / 전체 완화 | 부상 위험, 젊은 선수 성장, 라커룸 분위기 |
| 포지션 전환 제안 | 시킨다 / 그대로 둔다 | 적응 기간 수비 하락, 이후 라인업 유연성 |
| 타격폼 수정 | 맡긴다 / 말린다 | 성공 시 장타, 실패 시 슬럼프로 시작 |
| 주전 포수와 에이스의 불화 | 중재 / 전담 포수 교체 / 방치 | 배터리 호흡 수치, 한쪽 사기 |
| 유망주 깜짝 활약 | 개막 엔트리 약속 / 2군에서 더 | 약속 추적, 조기 콜업 압박 |
| 부상 조짐 | 정밀 검사로 2주 휴식 / 테이핑하고 강행 | 개막 결장 또는 시즌 중 큰 부상 확률 |

- 캠프가 끝나면 **캠프 결산** 화면: 눈에 띄게 달라진 선수 2~3명을 능력치 변화와 함께 보여 준다.
- 사건은 우리 선수 구성에서 뽑는다(신인이 없으면 신인 사건이 안 나온다).

## 3. 시범경기

경기 감각 수치는 없앤다. 대신 **주전 경쟁**.

- 캠프 종료 시 수석코치가 경쟁 자리 2~3개를 지정한다(예: 5선발, 주전 2루수, 마무리).
- 자리마다 후보 2명. 시범경기 6경기 동안 누구를 내보낼지 정하고, 성적이 쌓인다.
- 마지막에 **개막 엔트리 확정**: 자리마다 승자를 고른다. 성적이 좋은 쪽을 안 뽑으면 그 선수 사기가 떨어지고 언론 기사가 난다. 밀린 선수는 사기 하락 또는 트레이드 요청.
- 이 화면이 미뤄 둔 "개막 엔트리 확정 화면"을 겸한다.

## 4. 결과가 돌아오는 장치

- 결정마다 `state.fm.memo`에 한 줄을 남긴다: `{year, week, key, choice, who}`.
- 시즌 중 조건이 맞으면 기사나 편지로 되돌린다. 예: 캠프에서 새 구종을 배운 투수의 10승, 거절한 트레이드 상대 선수의 활약, 약속을 어긴 선수의 불만.
- 시즌 리캡에 **올해의 결정 3가지**를 넣는다.

## 5. 건너뛰기

- `단장에게 맡기기`: 그 주 사건을 무난한 선택으로 처리하고 요약만 보여 준다.
- `개막까지 맡기기`: 지금의 추천 준비 버튼. 모든 사건을 무난하게 처리한다.
- 맡긴 선택은 기대값이 약간 낮다. 직접 고르는 쪽이 조금 유리해야 한다.

## 6. 구현 단계

| 단계 | 내용 | 크기 |
|---|---|---|
| 1 | 사건 카드 틀: 사건 정의, 선택, 대가 적용, 메모 기록, 건너뛰기 | 중 |
| 2 | 스토브리그 6주: 고정 사건 6개 + 돌발 6개, 구단주 면담 | 대 |
| 3 | FA 면담과 약속 | 중 |
| 4 | 캠프 사건 7개와 캠프 결산 | 중 |
| 5 | 시범경기 주전 경쟁과 개막 엔트리 확정 | 중 |
| 6 | 되돌아오는 기사, 시즌 리캡의 올해의 결정 | 중 |

기존 세이브는 진행 중인 단계가 끝난 뒤 다음 시즌부터 새 흐름을 쓴다.

# 프로젝트 허구연 ⚾ (Project Heo Gu-yeon)

Football Manager 스타일의 **KBO 한국프로야구 매니지먼트 게임**. 브라우저에서 바로 플레이되는 단일 페이지 웹게임으로, KBO 공식 기록실의 2026 정규시즌 기록으로 만든 10개 구단 선수 데이터를 담고 있습니다. 감독 프로필을 만들고 10개 구단 중 하나를 골라 라인업을 짜고, 실시간 중계를 보며 경기에 개입하고, 트레이드로 전력을 보강해 가을야구에 도전하세요.

> 게임 이름은 KBO 총재이자 전설적인 야구 해설위원 **허구연** 위원님에서 따왔습니다.

## 실행 방법

1. `KBO매니저.html`, `core.js`, `fm.js` 를 **같은 폴더**에 둡니다.
2. `KBO매니저.html` 을 웹 브라우저로 엽니다. (별도 설치/서버 불필요)

> `core.js` 는 선수 데이터 + 경기 시뮬레이션 엔진, `fm.js` 는 받은편지함·사기·이사회·재정 같은 FM식 운영 시스템입니다. HTML이 같은 폴더에서 불러오므로 반드시 함께 두어야 합니다.

## 주요 기능

- **감독 취임 · 구단 선택** — 새 게임은 감독 이름과 경력(신인/코치 출신/레전드 출신)을 정하고, 전력 순위·핵심 선수·이사회 목표를 비교해 10개 구단 중 하나를 고르는 화면에서 시작
- **스토브리그 → 스프링캠프 → 시범경기 → 개막** — 새 커리어와 매 시즌은 스토브리그(FA 시장·외국인 선수·트레이드·재계약)에서 시작. 전지훈련 방향(타격/투수/수비·주루/체력/균형)을 정해 캠프를 마치면 시범경기 10경기(순위·기록 미반영)로 라인업과 작전을 시험한 뒤 개막
- **작전** — 팀 기본 전술과 경기별 작전: 타격 성향, 주루·도루, 희생번트, 팀배팅(진루타), 수비 시프트(병살·전진·외야 깊게), 배터리 볼배합(정면 승부·유인구), 고의4구, 투수 교체 타이밍. 프리뷰에 상대 전력분석 제안. 중계 중 🎯 작전 버튼으로 번트·도루·고의4구 지시와 작전 변경
- **실제 기록 기반** — 2026 정규시즌 소속·기록·생년월일·연봉으로 구단별 타자 14명·투수 12명 구성. 능력치는 기록을 엔진 공식에 역산해 계산하므로, 시즌 시뮬레이션이 실제 리그 타율·삼진율·볼넷률·홈런 수를 재현
- **타석 단위 시뮬레이션 엔진** — 삼진/볼넷/홈런/BABIP/병살/희생플라이/진루타/도루/실책까지 확률 계산. 선발은 투구수로 교체, 불펜은 한 이닝씩, 9회 1~3점 차엔 마무리
- **공식 기록 규칙** — 승리(선발 5이닝 조건)·패전(결승점 주자를 내보낸 투수)·세이브·홀드, 승계 주자 실점은 주자를 내보낸 투수에게, 실책 출루 득점은 비자책. 대타로 빠진 선수는 재출장 불가
- **수비 포지션** — 8개 수비 위치 + 지명타자를 직접 배치. 수비·송구 능력과 포지션 적합도가 팀 수비력이 되어 안타 허용률·장타·병살·실책에 반영. 자동 라인업은 출루율 중심 타순
- **엔트리 제출 → 실시간 중계** — 경기 전 프리뷰(선발 맞대결·예상 라인업)에서 엔트리 확정 후, 네이버 문자중계 스타일 화면에서 자동재생/속도조절하며 **투수 교체·대타**로 직접 개입
- **경기 리포트 · 인터뷰** — 경기마다 📰 피드에 리포트(이닝별 스코어, 승패 투수, 수훈 선수, 선발 투구 내용, 홈런). 끝내기·완봉·대량득점·연패 뒤엔 인터뷰 요청이 받은편지함으로 오고 답변이 사기와 이사회 신뢰도에 반영
- **선수 기록** — 프로필의 시즌 기록(wRC+·wOBA·ISO·BABIP·삼진/볼넷율, 투수 FIP·WHIP·K/9·K-BB%·선발 평균 이닝), 통산 기록(실제 KBO 2025년까지 + 게임 시즌 + 진행 중 시즌, 기록 달성 알림), 최근 10경기 로그
- **FM식 선수 프로필** — 능력치 1~20(FM 스케일)·레이더 차트·포지션 적합도·성격·최근 5경기 평점·연봉/계약·시장 가치, 칭찬/질책 면담·휴식 지정·트레이드 리스트·방출
- **컨디션 · 피로 · 사기 · 부상** — 경기에 나설수록 지치고 쉬면 회복. 투수 피로는 다음 경기까지 이어지고, 지친 선수는 부진하며 부상 위험이 커짐. 사기는 성적·출전 시간·면담·팀 미팅에 따라 변하고 능력에 반영
- **받은편지함** — 이사회 평가, 10경기마다 수석코치 보고(리그 대비 득실점·출루율·선발/불펜 평균자책 순위와 바로 적용할 교체 제안), 기자회견, 부상 보고, 선수 불만(출전 약속/경쟁/트레이드 요청 선택), 수석코치 피로 경고, AI 구단의 트레이드 제안, 계약 협상, 신인 입단 소식
- **구단 운영** — 이사회 시즌 목표와 신뢰도(크게 미달하면 경질), 관중 수입·연봉 지출·잔고, 연봉 예산 내 트레이드, 계약 만료 선수 재계약 협상(현재 연봉 기준), 오프시즌 FA 시장, 외국인 선수 교체(4명 정원 · 시즌 2회 · 108경기 전까지), 경질 시 다른 구단 감독 제의, 매년 신인 드래프트와 은퇴
- **시즌 운영** — 144경기 일정/순위/게임차, 타율·홈런·타점·도루·ERA·다승·세이브·홀드 리그 기록실(규정이닝 = 팀 경기 수)
- **트레이드** — 상대 AI가 선수 가치와 연봉 예산을 따져 수락/거절
- **포스트시즌** — 와일드카드(4위 1승 어드밴티지) → 준PO → PO → 한국시리즈를 한 경기씩 진행. 우리 경기는 프리뷰·실시간 중계로 직접 지휘하고, 경기마다 피로·부상이 쌓임
- **다년 플레이** — 시즌 종료 후 선수 나이·성장/노화 반영, 자동저장 + 저장/불러오기(localStorage)

## 파일 구성

| 파일 | 설명 |
|---|---|
| `KBO매니저.html` | 게임 UI · 시즌 운영 · 실시간 중계 화면 |
| `core.js` | 선수 데이터 · 경기 시뮬레이션 엔진 · 컨디션/부상 (DOM 비의존) |
| `career.js` | 선수별 KBO 정규시즌 연도별 기록 (2025년까지, `tools/fetch_career.js`로 생성) |
| `fm.js` | FM식 운영: 받은편지함 · 사기/면담 · 선수 프로필 · 이사회/재정/계약 |
| `data/kbo2026.json` | KBO 기록실에서 받은 원자료 (타격·투구·수비·주루 기록, 선수 프로필) |
| `data/players2026.csv` | 기록으로 계산한 전체 선수 능력치 (검토용, 엑셀로 열림) |
| `data/overrides.json` | 직접 고칠 값 (에디터) |
| `tools/` | 데이터 수집·변환·엔진 검증 스크립트 |

## 선수 데이터 관리 (에디터)

로스터와 능력치는 손으로 쓰지 않고 실제 기록에서 만듭니다. Node.js 18 이상이 필요합니다.

```bash
node tools/fetch_kbo.js 2026     # KBO 기록실에서 정규시즌 기록·선수 프로필 수집 → data/kbo2026.json
node tools/build_roster.js 2026  # 기록 → 능력치 변환, data/players2026.csv 작성, core.js 로스터 교체
node tools/fetch_career.js 2025  # 로스터 선수의 연도별 정규시즌 통산 기록 → data/career.json, career.js
```

- **변환 방식**: 엔진의 타석 공식을 거꾸로 풀어, 리그 평균 상대와 붙였을 때 선수의 실제 삼진율·볼넷률·홈런율·인플레이 타율이 나오는 컨택·선구·파워(투수는 구위·제구·무브먼트)를 구합니다. 70이 정확히 리그 평균이며, 리그 평균 비율은 `core.js`의 `LEAGUE`에 함께 기록됩니다. 타석·이닝이 적은 선수는 리그 평균 쪽으로 당깁니다.
- **주력**: 도루 시도율과 3루타. **수비·어깨**: 주 포지션의 수비 범위(자살+보살/9이닝)·실책·보살·포수 도루저지율.
- **로스터**: 구단별 타석 순 타자 14명(포수 2명 보장), 선발 등판 순 선발 5명, 세이브 1위 마무리, 이닝 순 불펜 6명. 시즌 중 이적한 선수는 더 많이 뛴 구단 소속.
- **직접 수정**: `data/overrides.json`에 선수 ID(players CSV의 첫 열) 또는 이름으로 값을 적고 `build_roster.js`를 다시 실행합니다.
  ```json
  { "김도영": { "fld": 82 }, "52605": { "team": "KIA", "pos": "SS" }, "홍길동": { "drop": true } }
  ```
  바꿀 수 있는 값: 타자 `con pow eye spd fld arm pos`, 투수 `stu ctl mov sta role`, 공통 `age sal team drop`.
- **엔진 검증**: `node tools/enginecheck.js core.js 10 --fatigue`는 리그 타율·삼진율·홈런 수를, `node tools/standcheck.js core.js 20`은 구단별 평균 승수를, `node tools/leadercheck.js core.js 3`은 시즌 다승·세이브·홀드·탈삼진·이닝·도루 1위와 선발 평균 이닝을 보여 줍니다. `core.js`의 `CAL`은 경기 중 투수 피로만큼을 상쇄하는 보정값입니다.

## 데이터 출처 및 면책

선수 기록·프로필은 [KBO 공식 기록실](https://www.koreabaseball.com/Record/Player/HitterBasic/Basic1.aspx)의 2026 정규시즌 자료이고, 능력치는 이를 게임 엔진에 맞게 환산한 **근사값**입니다. 재미를 위한 **비공식 팬 시뮬레이션**이며 KBO 및 구단과 무관합니다.

## 테스트

Node.js만 설치한 뒤 저장소 루트에서 `node tools/test.js`를 실행합니다(npm 패키지 불필요). 고정 난수 시드로 720경기 시즌의 투수 기록·리그 지표, 대타와 포지션, 작전별 400경기 비교, 포스트시즌 15이닝 제한, 통산 기록 배열을 검사합니다. 통과·실패·스킵 수와 실행 시간을 출력하며 실패 시 종료 코드가 0이 아닙니다. 알려진 게임 버그는 재현 테스트를 유지하고 `test.skip`에 원인과 위치를 명시합니다.

# 프로젝트 허구연 ⚾ (Project Heo Gu-yeon)

Football Manager 스타일의 **KBO 한국프로야구 매니지먼트 게임**. 브라우저에서 바로 플레이되는 단일 페이지 웹게임으로, 실제 KBO 2025 시즌 로스터·이적을 기반으로 한 10개 구단 전 선수 데이터를 담고 있습니다. 감독 프로필을 만들고 10개 구단 중 하나를 골라 라인업을 짜고, 실시간 중계를 보며 경기에 개입하고, 트레이드로 전력을 보강해 가을야구에 도전하세요.

> 게임 이름은 KBO 총재이자 전설적인 야구 해설위원 **허구연** 위원님에서 따왔습니다.

## 실행 방법

1. `KBO매니저.html`, `core.js`, `fm.js` 를 **같은 폴더**에 둡니다.
2. `KBO매니저.html` 을 웹 브라우저로 엽니다. (별도 설치/서버 불필요)

> `core.js` 는 선수 데이터 + 경기 시뮬레이션 엔진, `fm.js` 는 받은편지함·사기·이사회·재정 같은 FM식 운영 시스템입니다. HTML이 같은 폴더에서 불러오므로 반드시 함께 두어야 합니다.

## 주요 기능

- **감독 취임 · 구단 선택** — 새 게임은 감독 이름과 경력(신인/코치 출신/레전드 출신)을 정하고, 전력 순위·핵심 선수·이사회 목표를 비교해 10개 구단 중 하나를 고르는 화면에서 시작
- **실제 데이터 기반** — KBO 10개 구단 전 선수, 2025 시즌 성적·골든글러브·FA 이적 반영 (능력치는 기록 기반 근사값)
- **타석 단위 시뮬레이션 엔진** — 삼진/볼넷/홈런/BABIP/병살/희생플라이/주루까지 확률 계산, 선발 체력·불펜·마무리 운용 자동화
- **엔트리 제출 → 실시간 중계** — 경기 전 프리뷰(선발 맞대결·예상 라인업)에서 엔트리 확정 후, 네이버 문자중계 스타일 화면에서 자동재생/속도조절하며 **투수 교체·대타**로 직접 개입
- **FM식 선수 프로필** — 능력치 1~20(FM 스케일)·레이더 차트·포지션 적합도·성격·최근 5경기 평점·연봉/계약·시장 가치, 칭찬/질책 면담·휴식 지정·트레이드 리스트·방출
- **컨디션 · 피로 · 사기 · 부상** — 경기에 나설수록 지치고 쉬면 회복. 투수 피로는 다음 경기까지 이어지고, 지친 선수는 부진하며 부상 위험이 커짐. 사기는 성적·출전 시간·면담·팀 미팅에 따라 변하고 능력에 반영
- **받은편지함** — 이사회 평가, 부상 보고, 선수 불만(출전 약속/경쟁/트레이드 요청 선택), 수석코치 피로 경고, AI 구단의 트레이드 제안, 계약 협상, 신인 입단 소식
- **구단 운영** — 이사회 시즌 목표와 신뢰도(크게 미달하면 경질), 관중 수입·연봉 지출·잔고, 연봉 예산 내 트레이드, 계약 만료 선수 재계약 협상, 매년 신인 드래프트와 은퇴
- **시즌 운영** — 144경기 일정/순위/게임차, 타율·홈런·타점·ERA·다승·세이브 리그 기록실
- **트레이드** — 상대 AI가 선수 가치와 연봉 예산을 따져 수락/거절
- **포스트시즌** — 와일드카드(4위 1승 어드밴티지) → 준PO → PO → 한국시리즈
- **다년 플레이** — 시즌 종료 후 선수 나이·성장/노화 반영, 자동저장 + 저장/불러오기(localStorage)

## 파일 구성

| 파일 | 설명 |
|---|---|
| `KBO매니저.html` | 게임 UI · 시즌 운영 · 실시간 중계 화면 |
| `core.js` | 선수 데이터 · 경기 시뮬레이션 엔진 · 컨디션/부상 (DOM 비의존) |
| `fm.js` | FM식 운영: 받은편지함 · 사기/면담 · 선수 프로필 · 이사회/재정/계약 |

## 데이터 출처 및 면책

선수 능력치는 [KBO 공식 기록실](https://www.koreabaseball.com/Record/Player/HitterBasic/Basic1.aspx)의 실제 기록과 2025 시즌 타이틀·골든글러브·이적 정보를 바탕으로 환산한 **근사값**입니다. 재미를 위한 **비공식 팬 시뮬레이션**이며 KBO 및 구단과 무관합니다.
